# Editing and rebuilding the report

`report.tex` is the editable LaTeX source of [`../report.pdf`](../report.pdf) (two-column `extarticle` at 9 pt, A4, Times via `mathptmx`; no XeLaTeX or system fonts needed).

```bash
pdflatex -interaction=nonstopmode report.tex && pdflatex -interaction=nonstopmode report.tex
```

(or `latexmk -pdf report.tex`). Packages used — all in any full TeX Live / MiKTeX: `extsizes`, `geometry`, `mathptmx`, `amsmath`, `booktabs`, `graphicx`, `xcolor`, `hyperref`, `microtype`, `titlesec`, `caption`, `enumitem`, `stfloats`.

The five figures (`fig*.pdf`) are regenerated by `make_figs.py` from `_figdata.json` (a compact extract of the repo's run records, `results.csv`, instances and cached registers, produced by a short extraction script run inside the repo; it is included here so the figures rebuild without the repo):

```bash
python make_figs.py        # reads _figdata.json in this folder and rewrites fig*.pdf / fig*.png here
```

The brief caps the report at 4 pages; the build currently lands at exactly 4. If an edit pushes it to 5, the quickest levers are the `\includegraphics` widths of Figs. 1, 2, 4 (full-width) and the "What did not work" bullets.
