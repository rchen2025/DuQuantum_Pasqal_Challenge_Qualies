# qubo-solver 0.9.1 & qoolqit 1.4/1.5 — web-verified notes (2026-10-24)

(Code-level truth is in [`../api/qubosolver.md`](../api/qubosolver.md) and [`../api/qoolqit.md`](../api/qoolqit.md); this file keeps the links and the things only the docs/issues say.)

## qubo-solver
- PyPI 0.9.1 (2026-10-15): https://pypi.org/project/qubo-solver/ — 0.9.0 was a "major refactoring toward v1.0" with breaking renames (`SingleSolution→Candidate`, `HeuristicDriveShaper→ProportionalDiagonalDriveShaper`, `OptimizedDriveShaper→BayesianSearchDriveShaper`, `DecomposeQuboSolver` removed from the public config, BLaDE made default, cplex optional). Releases: https://github.com/pasqal-io/qubo-solver/releases
- Install: https://pasqal-io.github.io/qubo-solver/latest/get_started/install/ (`pip install qubo-solver`; heavy: torch, emu-mps, emu-sv, pandas, seaborn, scikit-optimize, swiglpk/GLPK, shapely).
- API reference (trust this + source, the user-guide/under-the-hood pages are partly STALE and still show `dmm=`, `use_quantum=True`, `DriveType`, κ=0.25): https://pasqal-io.github.io/qubo-solver/latest/api/solver/ , .../api/embedding/ , .../api/drive_shaping/ , .../api/classical_solving/ , .../api/hybrid_solving/ , .../api/quantum_solving/ , .../api/transforms/ , .../api/analysis/
- Quantum intro (Q_ii ↔ −2δ_i, Q_ij ↔ 1/r̃⁶): https://pasqal-io.github.io/qubo-solver/latest/user_guide/quantum/intro/ ; embedding https://pasqal-io.github.io/qubo-solver/latest/user_guide/quantum/embedding/ (BLaDE example 1.27 % error vs 44 % greedy on a 4×4); drive shaping under the hood https://pasqal-io.github.io/qubo-solver/latest/under_the_hood/driveshaping/local_energy_scale/ ; backends https://pasqal-io.github.io/qubo-solver/latest/user_guide/quantum/backend/ ; transforms https://pasqal-io.github.io/qubo-solver/latest/user_guide/classical/transforms/ ; quickstart https://pasqal-io.github.io/qubo-solver/latest/get_started/quickstart/ ; tutorial https://pasqal-io.github.io/qubo-solver/latest/tutorials/02-qubosolver-in-full/
- Backend selection: `LocalEmulator(num_shots=…)` auto: QutipBackendV2 (<15), SVBackend (15–25), MPSBackend (≥26); `RemoteEmulator` defaults to the free QuTiP engine (fails >~15 qubits); `AutoRemoteEmulatorBackend` may incur fees; `qoolqit.execution.QPU(connection, num_shots)` + `Device.from_connection(conn, "FRESNEL_CAN1")`.
- Seeds: `torch.manual_seed` for classical solvers; BLaDE uses numpy's global RNG; the emulator sampling seed is not exposed; docs use the private `qubosolver.utils._random.manual_seed(…)`.
- Docs example of the Bayesian drive search: optimum found with 0.9 % probability while the worst bitstring had 77.8 % — sampled distributions are not sharply peaked; rely on post-processing/cost sorting.
- Open issues: https://github.com/pasqal-io/qubo-solver/issues (#105/#102 reduce deps, #108 SA, #106 decomposition sub-QUBOs). Logging: `logging.getLogger("qubosolver").setLevel(logging.DEBUG)`.

## qoolqit
- PyPI 1.4.0 (2026-08-20) https://pypi.org/project/qoolqit/ ; the venv has 1.5.0 (main). Releases https://github.com/pasqal-io/qoolqit/releases : 1.4.0 changed the **default compile profile to DEFAULT** (was max_energy) and accepts string profiles; 1.3.0 added `Register.circle/line/square/...`, `interaction_matrix()`; 1.2.0 removed Sin/custom waveforms (PCHIP only), added `AnalogDeviceWithDMM`.
- Model: https://pasqal-io.github.io/qoolqit/latest/get_started/qoolqit_model/ — H̃ = Σ J̃_ij n_i n_j + Σ Ω̃/2 σx − Σ (δ̃ + ε_i Δ̃) n_i with J̃ = 1/r̃⁶, r̃ ≥ 1, Δ̃ ≤ 0, ε_i ∈ [0,1].
- Compilation: https://pasqal-io.github.io/qoolqit/latest/fundamentals/compilation/device_and_compilation/ , rationale .../fundamentals/compilation/rationale/ , errors .../fundamentals/compilation/error_handling/ — `compile_to(device, profile="default"|"max_energy", device_max_duration_ratio=None)`; `max_energy` rescales so Ω̃_max→device max amp or min distance→device min, whichever binds; still raises `CompilationError` on radial/detuning/duration. Open issue #157: max_radial_distance not always enforced; #462 default BladeConfig can lead to compilation failure.
- Devices: `MockDevice()`, `AnalogDevice()`, `AnalogDeviceWithDMM()`, `DigitalAnalogDevice()`, `Device(pulser_device=…)`, `Device.from_connection(conn, "FRESNEL")`; `.specs` keys `max_duration, max_amplitude, max_abs_detuning, min_distance, max_radial_distance`. Dimensionless AnalogDevice: Ω̃_max 0.2268, δ̃_max 2.268, T̃_max 332.44, r̃_min 1, R̃ 7.6.
- Embedding: https://pasqal-io.github.io/qoolqit/latest/fundamentals/embedding/ , custom embedders .../extended_usage/custom_embedders/ — `InteractionEmbedder(InteractionEmbedderConfig(method="Nelder-Mead", maxiter=200000, tol=1e-8, seed=None))` (diagonal ignored), `Blade(BladeConfig(...device=))`, `SpringLayoutEmbedder` (unit-disk / MIS).
- Execution: https://pasqal-io.github.io/qoolqit/latest/fundamentals/execution/execution/ , quick run .../get_started/quick_run_guide/ — `LocalEmulator(backend_type=BackendType.QutipBackendV2|SVBackend|MPSBackend, emulation_config=None, num_shots=None).run(program).results().final_bitstrings`; remote `RemoteEmuFreeBackend|RemoteSVBackend|RemoteMPSBackend`; `QPU(connection, num_shots)`; `job.get_status()`, `retrieve_remote_job(connection, job_id, batch_id)`.
- Tutorials: QUBO https://pasqal-io.github.io/qoolqit/latest/tutorials/solving_a_qubo/ (normalises Q by its max, global detuning only), MWIS with DMM https://pasqal-io.github.io/qoolqit/latest/tutorials/Solving_a_MWIS/ (d_i = −Q_ii/2, ε_i = (d_max−d_i)/(d_max−d_min), DMM constant −(d_max−d_min)).
- No solver classes in qoolqit itself; QUBO solving is delegated to qubo-solver. Single global Rydberg channel + at most one DMM; no parametrized sequences/optimizers; noise only via pulser `noise_model` passthrough.
