## pulser-simulation (QuTiP)
- 1.9.1, https://pypi.org/project/pulser-simulation/ ; tutorials https://pulser.readthedocs.io/en/stable/tutorials/simulating.html , backends https://pulser.readthedocs.io/en/stable/tutorials/backends.html , noise https://pulser.readthedocs.io/en/stable/tutorials/noisy_sim.html ; API https://pulser.readthedocs.io/en/stable/apidoc/_autosummary/pulser_simulation.qutip_backend.QutipBackendV2.html , .../pulser_simulation.qutip_config.QutipConfig.html
- Knobs: `sampling_rate` (0.1 is fine for smooth pulses, ~10× faster), `default_evaluation_times`, `with_modulation`, `noise_model=pulser.NoiseModel(...)` (types: leakage, doppler, amplitude, detuning, register, SPAM, dephasing, relaxation, depolarizing, eff_noise, dmm_sigma, dmm_crosstalk), `n_trajectories`, `solver`.
- Ceiling: dense 2^N on CPU; tutorial 14-atom ring ≈ 20 s at sampling_rate 0.1; cloud docs call it "≤10–12 qubits"; emu-sv beats it from ~9 qubits.

## emu-sv 2.10.0
- https://pypi.org/project/emu-sv/ , docs https://pasqal-io.github.io/emulators/latest/emu_sv/ , API .../emu_sv/api/ , benchmarks .../emu_sv/benchmarks/performance/ and .../accuracy/ , notebook .../emu_sv/notebooks/getting_started/
- Python 3.11–3.14; `emu-base==2.10.0` → `pulser-core[torch]>=1.9`, `torch~=2.7`; installing may upgrade pulser-core. GPU: install the CUDA torch build yourself; `SVConfig(gpu=None)` auto-selects.
- `SVConfig(dt=10.0, max_krylov_dim=100, krylov_tolerance=1e-10, gpu=None, interaction_cutoff=0.0, log_level=INFO, log_file=None, solver=Solver.DEFAULT, **EmulationConfig)`. Evaluation times must be multiples of `dt` (relative).
- Ceiling: "best for noiseless up to ~25 qubits"; ~27 on an A100 40 GB; GPU ≈ 4× CPU; runtime ~doubles per qubit; noise (Lindblad density matrix) halves the count (~12–13). Cloud EMU_SV cap 25.
- Accuracy: piecewise-constant H per dt (error ∝ dt²).

## emu-mps 2.10.0
- https://pypi.org/project/emu-mps/ , docs https://pasqal-io.github.io/emulators/latest/emu_mps/ , API .../emu_mps/api/ , config .../emu_mps/advanced/config/ , errors .../emu_mps/advanced/errors/ , convergence .../emu_mps/advanced/convergence/ , resources .../emu_mps/advanced/resource_estimation/ , benchmarks .../emu_mps/benchmarks/accuracy/ and .../performance/
- `MPSConfig(dt=10.0, precision=1e-5, max_bond_dim=1024, max_krylov_dim=100, extra_krylov_tolerance=1e-3, gpu=None, optimize_qubit_ordering=True, interaction_cutoff=0.0, autosave_prefix="emu_mps_save_", autosave_dt=inf, solver=Solver.TDVP|DMRG, **EmulationConfig)`; `MPSBackend.resume(autosave_file)`; `MPS.sample(num_shots, p_false_pos, p_false_neg)`, `entanglement_entropy(site)`, `get_max_bond_dim()`.
- Practical: cloud "≤60–80 qubits", good for N≈40 in 2D and ≈100 in 1D at ~10 µs pulses; 7×7 adiabatic grid at χ=1600 took ~100 s/step on a 30 GB GPU. Memory GPU < 8χ²(16N+8k+46) B; CPU < 4χ²[N(N+36)+16k+72] B; runtime/step ~ αN²χ³ + βN³χ².
- Trust: TDVP is 1D; 2D registers are snaked into a chain, long-range terms via a partial-trace approximation; reliable for 1D/quasi-1D, low entanglement, short quenches. Error sources: long-range projection, O(dt²) Trotter, Krylov, truncation ≤ 2(N−1)·precision per step. Too small dt (≲1–5 ns) hurts.
- Convergence recipe (docs): tighten `precision` (1e-5→1e-6→1e-7), raise `max_bond_dim` and confirm χ stays below it (`results.statistics[-1]["max_bond_dimension"]` / step log), lower dt, compare overlaps/observables across settings (docs example χ 1600 vs 1800 overlap 0.999), watch Energy/EnergyVariance drift, cross-check vs emu-sv ≤ 25 qubits. Noisy runs: loop `backend.run()` and `Results.aggregate(list)`.
- Common base classes: https://pasqal-io.github.io/emulators/latest/base_classes/ ; `pulser.backends` lazily exposes `QPUBackend, QutipBackend, QutipBackendV2, RemoteEmuFreeBackend, RemoteMPSBackend, RemoteSVBackend, MPSBackend, SVBackend`. `StateResult` is not available on remote backends.

## pasqal-cloud 0.24.0
- https://pypi.org/project/pasqal-cloud/ (2026-09-08, Alpha); docs https://pasqal-io.github.io/pasqal-cloud/ (getting started, authentication, regions, migrating-from-pulser-pasqal, reference/pasqal_cloud_client, reference/pasqal_cloud_connection, reference/backends); cloud docs https://docs.pasqal.com/cloud/ (emulators, batches, fresnel-job, REST create_batch); CHANGELOG https://raw.githubusercontent.com/pasqal-io/pasqal-cloud/main/CHANGELOG.md
- `pulser-pasqal` 0.23.0 is deprecated ("replaced by pasqal-cloud").
- Public API: `PasqalCloudConnection(username='', password='', project_id='', region='fr'|'sa', **client_kwargs)` (omit password → prompt; `token_provider=` alternative; `OVHConnection()` reads `PASQAL_PULSER_ACCESS_TOKEN`), `RemoteMPSBackend/RemoteSVBackend/RemoteEmuFreeBackend(sequence, connection, *, config=None, mimic_qpu=False)`, `.run(job_params=[{"runs": N, "variables": {...}}], wait=False) -> pulser.backend.RemoteResults` (`batch_id`, `job_ids`, `get_batch_status()`, `get_available_results()`, `.results`), `with bk.open_batch(): ...`.
- Raw client `pasqal_cloud.pasqal_cloud_client.PasqalCloudClient(username, password, token_provider, endpoints, webhook, project_id, client_class, region, auth_config)` (`SDK` is a deprecated alias): `create_batch(serialized_sequence, jobs, open=False, device_type=DeviceTypeName.X, backend_configuration=EmulationConfig.to_abstract_repr(), wait=False, tags=[])`, `get_batch(id)`, `get_job(id, wait=False)`, `get_batch_status(id)`, `get_job_status(id)`, `get_batches(filters, pagination_params)`, `get_jobs(JobFilters(...))`, `cancel_batch/cancel_job/cancel_jobs`, `rebatch(batch_id, RebatchFilters(status=JobStatus.ERROR))`, `add_jobs(batch_id, jobs)`, `close_batch(id)`, `get_device_specs_dict()` (device type → serialized specs; `pulser.json.abstract_repr.deserializer.deserialize_device`).
- Enums: `DeviceTypeName = EMU_FREE, EMU_TN, EMU_FRESNEL, EMU_MPS, EMU_SV, FRESNEL, FRESNEL_CAN1` (REST also FRESNEL_SA1, FRESNEL8, …); `BatchStatus = PENDING, RUNNING, DONE, ERROR, CANCELED, TIMED_OUT` (+ CANCELING, PAUSED on REST); `JobStatus = PENDING, RUNNING, DONE, ERROR, CANCELED`; `EmulatorType` deprecated (no EMU_SV).
- Emulators on cloud: EMU_FREE = pulser-simulation CPU ~10–12 qubits (optional SPAM noise); EMU_SV ≤25 qubits (GPU); EMU_MPS ≤80 (Constant/Ramp/Blackman/Interpolated waveforms only); EMU_TN legacy/deprecated; EMU_FRESNEL = same validation as the QPU (pre-check QPU jobs).
- Results: `job.result` = `{bitstring: count}` (= `full_result["counter"]`); pulser path `Results.final_bitstrings`. Polling: `wait=True` polls every 2 s (0.24.0); 429s retried honouring Retry-After.
- Gotchas: project_id required (billing); no built-in env-var names for credentials (we use PASQAL_USERNAME/PASSWORD/PROJECT_ID); max 1000 runs/job and 6000 ns on FRESNEL_CAN1; batch DONE means all jobs terminal (check each `job.status`); open batches must be closed; QPU queue FIFO, no availability calendar — test with EMU_FRESNEL; QPU needs a layout-backed register; deprecated: `emulator=`, `configuration=`, `fetch_results=`, `complete=`, `SDK`, root re-exports; keep pulser 1.9.x + pasqal-cloud 0.24 together; `region="sa"` for the Saudi platform.
